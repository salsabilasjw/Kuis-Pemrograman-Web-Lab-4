# TaskFlow — To-Do List React

Aplikasi To-Do List frontend untuk kuis praktikum Pengembangan Frontend.

## Fitur
- Menampilkan daftar tugas dengan data dummy
- Melihat detail tugas
- Menambah tugas
- Mengedit tugas
- Menghapus tugas dengan konfirmasi
- Pencarian tugas dan filter status
- React State untuk mengelola perubahan data tanpa reload halaman

## Teknologi
- React.js
- Vite
- CSS

## Cara menjalankan
Pastikan Node.js sudah terpasang.

```bash
npm install
npm run dev
```

Buka alamat lokal yang muncul di terminal (umumnya `http://localhost:5173`).

## Build
```bash
npm run build
```
